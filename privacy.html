ENGLISH

Alpha data handling notice

What is stored?

A running cooperative Node server stores the brand, product description, user-provided evidence, audience details, game messages, AI consent choices and final campaign dossier in its local SQLite database. The two agent access-token hashes are stored, not the raw tokens. The raw bearer token is held in your browser tab's sessionStorage. Your language preference is stored in localStorage. The server does not set marketing cookies or run third-party analytics in this version.

Who sees which data?

Before finalization, Agent Vector sees their product information and Agent Echo sees their audience information. Both see the shared messages. After finalization, the generated dossier combines information from both roles. Whoever possesses an agent bearer token can act in that role. A room code alone can claim an unoccupied second role. Do not enter client secrets, regulated data or personal information.

AI requests

By default the dossier is created using local rules, with no model API call. If an API provider is configured, both agents must independently opt in before private mission content is sent to OpenAI for creative refinement. Either agent may revoke consent until the dossier is finalized. The service requests store: false for OpenAI Responses API calls; upstream processing and retention follow the provider's applicable policies. Consent is a product-level safeguard, not proof of legal compliance. Verify all advertising claims.

Export, deletion and retention

  • Each authorized agent may download a JSON export of their role-specific view, including shared messages and, after finalization, the dossier. Raw access tokens are never included.
  • Either authorized agent can delete the entire room by entering its exact room code in a confirmation dialog. Both agents immediately lose access.
  • Rooms expire seven days after creation. The server prunes expired rooms on startup and then hourly, so deletion may happen after the seven-day mark; if the server is offline, cleanup resumes when it restarts.
  • The local SQLite database is configured with secure-delete and attempts to truncate the write-ahead log after erasure. This cannot guarantee removal from backups, filesystem snapshots or physical storage media. No production backup or deletion policy has been established.

Five playable creative worlds and local report import

AntiPersona, Brief Theatre, AdBiome, Museum of Attention and Attention Republic are authored client-only creative workshops. Their project fields, choices and notes stay in the tab's runtime memory; there is no automatic localStorage, analytics SDK, AI request or report submission. An optional JSON export explicitly downloads the user's project text and decisions. Static files are still served over HTTP(S), and the hosting provider may retain separate access logs.

Commercial Command can read such a JSON file locally to prefill an editable campaign draft; importing alone does not transmit project data, save a campaign, prove a product claim or publish an advertisement. Only a separate authorized Save Draft action sends the reviewed campaign to the server's normal workspace database.

Pilot Studio requests and Experiment Lab

Commercial pilot forms (Pilot Studio) store company, contact, email, optional HTTPS website, business objective, budget band and language in the server's SQLite database only after explicit consent. The operator can access these contact details using a configured shared secret. A random deletion token is shown once and only its hash is saved; submitted contact details are eligible for removal after 90 days with scheduled cleanup. Unverified commercial claims are not collected as payments.

Experiment Lab is different: an opt-in participant receives a random A/B assignment. The SQLite database stores only random session and experiment identifiers, A/B arm, a hash of a bearer token, the technical session timestamp and a CTA flag. The chosen narrative branch stays in browser memory and is not sent to the API. The client uses no experiment cookies or persistent storage. Session rows expire after seven days; day-by-arm aggregates expire after 90 days. Technical session starts and CTA clicks are not verified human impressions, leads or purchases.

The experiment server temporarily uses a requester's IP address in volatile memory for per-address abuse throttling (up to one hour); hosting/proxy logs may independently contain IP addresses. Public deployments still need a reviewed privacy notice, lawful basis and data-controller documentation. See the source documentation for implementation limits.

Commercial Command workspace, proposals and optional attribution

Commercial workspaces store an organization name, its randomly generated identifier, SHA-256 hashes of workspace access credentials, role/expiry metadata and an action audit log. Campaigns store authored audience, offer, copy and status. Commercial proposals additionally store the proposed client's company name and contact email, description of service, currency, calculated nominal value and manually/privately recorded decision. Proposal contact records are eligible for deletion after 180 days and are cleaned on server startup, hourly and during normal access. Workspace records persist until the authorized owner deletes the workspace; backups, infrastructure logs and snapshots are not automatically erased by the application.

An authorized workspace owner may export workspace records (including client emails), and may permanently delete all active workspace campaigns, proposals, access tokens and audit entries by confirming the exact organization name. Public creative previews and private proposal links become inaccessible. Global Pilot Studio applications and cooperative Dead Drop mission data are separate datasets and must be managed through their own removal controls. Shared access tokens are not verified human login identities; public operation requires secure hosting and review.

If a person explicitly opts into Experiment Lab, clicks its CTA and later separately consents to submit a Pilot Studio contact form in the same tab, a short-lived one-time attribution receipt may link the technical experiment assignment (A or B) to their submitted contact details. The receipt stays in sessionStorage until used or expired, never in the URL. The database stores the experiment ID and assigned arm on the lead. A valid form submission is not proof of a real, unique or paying customer. Any client identification, analytics and payment operation requires independent review.

Hosting and status

Static training simulation stays in your browser; it does not send mission input to the multiplayer API. When a private or self-hosted multiplayer server is running, it stores data on that host. A public deployment with HTTPS, verified data controller, privacy assessment and operational retention procedures has not been confirmed.

For technical questions, consult the source repository. Do not post personal data in public repository issues.

РУССКИЙ

Уведомление об обработке данных в альфа-версии

Какие данные сохраняются?

Работающий сервер Node хранит в локальной базе SQLite название бренда, описание продукта, указанные пользователем доказательства, сведения об аудитории, сообщения агентов, выбор согласия на ИИ и итоговое рекламное досье. Сохраняются хеши токенов доступа, но не сами токены. Токен находится в sessionStorage вкладки браузера, а выбранный язык — в localStorage. В текущей версии нет маркетинговых cookie и сторонней аналитики.

Кто видит информацию?

До завершения миссии агент Вектор видит закрытые сведения о продукте, агент Эхо — сведения об аудитории. Сообщения видны обоим. Итоговое досье объединяет информацию двух участников. Любой обладатель токена может действовать от имени соответствующего агента, а код свободной комнаты позволяет присоединиться второму участнику. Не вводите персональные, конфиденциальные или регулируемые данные.

Запросы к ИИ

По умолчанию досье создаётся локальными правилами без внешнего ИИ. Если серверный API настроен, оба агента должны отдельно согласиться на передачу данных миссии в OpenAI для улучшения текста. До финализации согласие можно отозвать. Программа передаёт параметр store: false, но обработка данных провайдером регулируется его действующими условиями. Согласие в интерфейсе не подтверждает юридическое соответствие требованиям GDPR. Рекламные утверждения необходимо проверять.

Экспорт, удаление и сроки хранения

  • Каждый агент может скачать JSON с данными, которые доступны его роли, общими сообщениями и, после завершения, рекламным досье. Токены доступа в экспорт не входят.
  • Любой из двух агентов может удалить всю комнату, введя её точный код в подтверждающем окне. Доступ обоих участников прекращается.
  • Срок хранения комнаты — семь дней от создания. Сервер удаляет просроченные комнаты при запуске и затем каждый час. Во время простоя сервера удаление выполняется после перезапуска.
  • SQLite настроена с secure_delete; после удаления сервер пытается очистить журнал WAL. Это не гарантирует физического удаления из резервных копий, снимков диска и носителей. Промышленная политика резервирования и удаления ещё не создана.

Пять творческих миров и локальный импорт сценариев

AntiPersona, Brief Theatre, AdBiome, Museum of Attention и Attention Republic — самостоятельные браузерные творческие тренажёры. Название проекта, выборы и реплики хранятся только в оперативной памяти вкладки. Приложения не отправляют их в API, не сохраняют автоматически в localStorage, не используют SDK аналитики и не обращаются к генеративному ИИ. Пользователь может самостоятельно скачать JSON с введёнными сведениями. Обычные HTTP(S)-логи хостинга существуют отдельно от игровой логики.

Commercial Command может локально прочитать такой JSON и заполнить редактор кампании. Сам импорт не передаёт файл на сервер, не сохраняет запись, не подтверждает рекламное обещание и не публикует рекламу. Только отдельное нажатие «Сохранить черновик» с действующим доступом к организации отправляет отредактированные данные в SQLite.

Заявки Pilot Studio и эксперименты

В Pilot Studio после явного согласия сохраняются сведения о компании, контактном лице, рабочей почте, необязательном HTTPS-сайте, цели, примерном бюджете и языке. Оператор сервера получает доступ к этим сведениям по общему секретному токену. Пользователю один раз выдаётся ключ для удаления; в базе хранится только его хеш. Заявки подлежат удалению после 90 дней с периодической очисткой. Никакой статус заявки сам по себе не подтверждает оплату.

Experiment Lab собирает другие, обезличенные данные: после согласия посетитель получает случайную версию A/B. В SQLite сохраняются случайные идентификаторы сессии и эксперимента, версия, хеш токена, время начала и флаг CTA. Сюжетный выбор остаётся в памяти вкладки. Cookie эксперимента и постоянное браузерное хранилище не используются. Сессии хранятся до 7 дней, суточные агрегаты — до 90 дней. Эти показатели не подтверждают реальные показы людям, заявки или покупки.

Для защиты от массового создания сессий IP временно удерживается в оперативной памяти сервера (до часа); прокси и журналы хостинга могут независимо сохранять IP. Публичная эксплуатация потребует юридической оценки и документов об операторе данных, основаниях обработки и сроках хранения.

Рабочие пространства Commercial Command, предложения и связка заявок

Коммерческое пространство сохраняет название организации, случайный идентификатор, хеши ключей доступа, сведения о ролях и сроках действия, журнал событий, тексты и статусы кампаний. Предложения дополнительно содержат название заказчика, контактную почту, описание услуг, валюту, расчётную стоимость и решение по приватной ссылке. Контактные сведения предложений подлежат очистке после 180 дней; при обычной работе сервера очистка выполняется при запуске, каждый час и при доступе. Другие записи пространства существуют до удаления уполномоченным владельцем. Программа не может автоматически удалить резервные копии, логи и снимки дисков.

Владелец может выгрузить рабочие записи (включая адреса заказчиков), а также удалить всю организацию с кампаниями, предложениями, ключами и журналом, введя точное название. Публичные макеты и приватные ссылки после этого станут недоступны. Отдельные заявки Pilot Studio и комнаты Dead Drop не относятся к данным организации: они удаляются своими механизмами. Разделение по случайным ключам — не юридическая верификация личности и не полноценные учётные записи сотрудников.

При отдельном согласии на A/B-исследование, последующем нажатии CTA и новом согласии на отправку контактной заявки Pilot Studio короткоживущее одноразовое подтверждение может связать заявку с назначенной группой A/B. Подтверждение хранится в sessionStorage вкладки и не попадает в URL. В заявке сохраняются ID эксперимента и группа. Это позволяет считать реально отправленные формы, но не доказывает настоящего уникального клиента, оплату или выручку.

Размещение и юридический статус

Тренировка без сервера работает только в браузере. Настоящие онлайн-миссии сохраняются там, где запущен Node-сервер. Публичный сервер с HTTPS, установленным оператором данных, правовой оценкой и проверенными процедурами хранения ещё не подтверждён.

Исходный код размещён на GitHub. Не публикуйте персональные сведения в открытых обращениях репозитория.

测试版数据处理说明

保存哪些信息？

运行中的 Node 服务器将品牌、产品描述、用户提供的证据、受众信息、游戏消息、AI 同意状态和最终广告档案存储在本机 SQLite 数据库中。服务器保存访问令牌的哈希值，不保存原始令牌。原始令牌保存在浏览器标签页的 sessionStorage 中，语言偏好保存在 localStorage 中。当前版本不设置营销 Cookie，也不使用第三方分析服务。

谁能查看数据？

任务完成前，向量特工仅能查看自己的产品私密信息，回声特工仅能查看自己的受众私密信息，双方均可查看共同传递的消息。最终档案将融合双方信息。持有代理令牌的人可以使用该角色，拥有未被领取房间代码的人可以作为第二位特工加入。请勿输入个人隐私、商业机密或受监管的数据。

AI 请求

默认情况下，系统只使用本地规则生成档案，不调用外部 AI。如果服务器配置了 AI，双方特工必须分别明确同意，系统才会将任务数据发送给 OpenAI 优化创意。任意一方可在最终生成前撤回同意。服务请求使用 store: false，但上游处理和保留仍以服务商适用政策为准。产品中的同意选项不等同于法律合规性证明。发布广告前必须人工核实事实。

导出、删除与保留

  • 每位特工可将自身角色可见的信息、共享消息及完成后的广告档案导出为 JSON。导出不包含原始访问令牌。
  • 任何一位授权特工都可以输入准确房间代码确认删除整个房间。删除后双方均失去访问权限。
  • 房间在创建七天后过期。服务器启动时及之后每小时清理过期房间；如果服务器离线，则在下次启动时清理。
  • SQLite 启用 secure_delete，并在删除后尝试截断 WAL 日志。这并不保证备份、磁盘快照或物理介质中的数据被完全清除。目前尚未制定生产级备份与删除政策。

五个创意世界与本地报告导入

AntiPersona、Brief Theatre、AdBiome、Museum of Attention 和 Attention Republic 都是在浏览器运行的创作互动体验。品牌、用户选择和台词仅保存在当前标签页内存中，不会自动存入 localStorage，也不会发送分析 SDK、AI 或业务 API。用户可主动下载包含自己所填信息的 JSON 文件。静态网页的 HTTP(S) 访问日志属于单独的托管环境。

Commercial Command 可以在浏览器中读取该文件并预填广告草稿。单纯导入不会上传文件、保存活动或发布广告。只有拥有组织权限的用户再次选择保存草稿时，已编辑的数据才会发送到服务器数据库。

Pilot Studio 申请与 Experiment Lab 实验

在明确同意后，Pilot Studio 将公司、联系人、邮箱、可选 HTTPS 网站、目标、预算范围和语言保存在服务器 SQLite 中。经授权的运营者可通过共享密钥读取这些数据。申请人仅收到一次随机删除密钥，数据库只保存哈希值；联系信息可在最多 90 天后按计划清理。申请状态不代表已付款。

Experiment Lab 仅在参与者明确同意后随机分配 A/B 创意。SQLite 只保存随机会话/实验标识、分组、令牌哈希、开始时间和 CTA 点击标记。故事选项只存留在浏览器标签页的内存中，不会上传。实验不使用 Cookie 或持久浏览器存储。会话数据最长 7 天、按日汇总数据最长 90 天。这些技术指标不是经过核实的真实用户展示、线索或购买量。

服务器为防止滥用，会在内存中短暂使用请求者 IP（最多一小时）；托管服务或代理日志仍可能单独保留 IP。正式上线之前必须核查隐私声明、法律依据和数据处理责任。

Commercial Command 工作空间、报价与可选归因

商业工作空间存储组织名称、随机标识符、访问令牌的 SHA-256 哈希、角色和有效期、操作日志、广告活动的创意与状态。报价记录还保存潜在客户的公司名称和联系邮箱、服务范围、币种、拟议金额和通过私密链接作出的决定。报价联系记录最多保留约180天；服务启动、每小时和日常访问时执行清理。其他工作空间数据由授权所有者主动删除；服务端备份、日志和磁盘快照仍需要独立删除方案。

所有者可导出包含联系人邮箱的工作空间数据，并通过输入准确组织名称删除活动、报价、访问令牌和审计记录。公开预览和私人报价链接随即失效。Pilot Studio 的独立申请以及 Dead Drop 的房间数据不属于此工作空间删除范围。随机令牌权限不等于经过法律验证的自然人身份。

用户明确同意参加 A/B 实验、点击 CTA，随后又明确同意在同一标签页提交联系表单时，短期一次性归因凭据可能将申请与实验的 A/B 组关联。该凭据只在 sessionStorage 中暂存，不放入 URL；申请记录保存实验 ID 和组别。提交申请不证明独立真实客户、付款或营业收入。

托管与状态

静态训练仅在浏览器中进行，不会将任务数据发送至多人协作 API。多人游戏数据存储在实际运行 Node 服务器的主机上。公开 HTTPS 部署、经验证的数据控制者、隐私评估和正式保留流程尚未确认。

Data handling for the other Impossible Ventures prototypes

Local-only creative tools

Appeal 2049, AntiPersona, Brief Theatre, AdBiome, and Museum of Attention run their creative engines in your browser without submitting your campaign input, local reports or visitor placards to the Node API. A report is written to your device only if you request a download. File imports such as Dead Drop dossiers are read locally by JavaScript. The browser may remember display-language preferences; do not upload client secrets into these experimental frontends. This description does not prevent hosting providers from retaining ordinary web request or network logs.

Creative Pipeline and Economics Studio

Creative Pipeline reads supported creative JSON files locally, excludes arbitrary token fields from imported commercial drafts, and only exports a reviewed unsaved file on request. A subsequent save in Commercial Command requires an authorized user action. Economics Studio models user-entered assumptions in the browser; scenario reports are not verified purchases, actual revenue, financial statements or regulated investment advice. Neither local tool submits draft contents or financial inputs to our API.

Attention Republic — optional real anonymous ballots

Before choosing an option, a participant may explicitly cancel their unvoted session with their own bearer token. A successful cancellation removes the session record from active SQLite without recording a ballot. After a vote has been cast, this endpoint cannot erase the aggregated result; individual deletion of historic anonymous ballots is not supported. A proxy or backup may retain transport or historical data under its own retention configuration.

Static demo ballots are never sent to the API. On a running Node server, an operator first publishes a challenge. Only after explicit participation consent is a 7-day anonymous session created. The server stores a random session ID, a SHA-256 access-token digest, the associated question, time and at most one selected option. The original raw bearer token is kept in the browser tab's memory and discarded after a successful vote. A daily count of A/B ballots is stored up to 90 days. These are technical session ballots, not verified unique people, and no anti-sybil/identity guarantee is offered. Deleting or closing the question does not automatically erase historic aggregates. The prototype currently offers no way to target an individual anonymized ballot for deletion after submission.

Rate-limit counters temporarily keep network source addresses in process memory; infrastructure proxies and host logs may have their own IP retention policies. Operator challenge controls use a shared server secret, not production-grade account authentication. Challenges expire after 14 days. Real backups may still contain old records even after live retention purges; no off-site backup retention process has been verified.

Pilot Studio and Experiment Lab

Pilot Studio stores self-submitted contact leads with consent for up to 90 days and supplies a deletion token for a specific lead. Experiment Lab stores anonymous consented A/B sessions for up to 7 days and daily aggregates for 90 days. These aggregates measure technical events only, not guaranteed human impressions, unique users or sales. Neither is a payment or advertising delivery network. Their server-side storage behavior differs from the local-only creative pages.

Legal and deployment caveat

This is an experimental implementation notice, not a published controller agreement, data processing addendum, legal opinion or proof of GDPR compliance. Operating organizations must establish lawful basis, privacy contacts, hosting regions, secure authentication, log policy, incident response, user rights processes and deletion across backups before processing real customer data.

Обработка данных в остальных продуктах Impossible Ventures

Локальные креативные инструменты

Appeal 2049, AntiPersona, Brief Theatre, AdBiome и Museum of Attention обрабатывают введённые идеи в браузере и не отправляют текст кампаний, локальные отчёты и музейные таблички в Node API. Импорт JSON-досье читается локально, а скачивание происходит только после действия пользователя. Браузер может запоминать язык интерфейса. Это не исключает обычные сетевые журналы провайдера хостинга. Не вводите реальные секреты клиентов в исследовательские инструменты.

Creative Pipeline и Economics Studio

Creative Pipeline локально читает творческие JSON-файлы, не переносит произвольные секретные поля и передаёт рекламный черновик только по команде пользователя. Сохранение в Commercial Command требует отдельного подтверждения авторизованным пользователем. Economics Studio рассчитывает три условных финансовых сценария по введённым пользователем параметрам. Это не подтверждённые продажи, выручка, бухгалтерский отчёт или финансовая рекомендация. Содержимое файлов и расчётов не отправляется в API этих локальных инструментов.

Attention Republic — добровольные анонимные голосования

До выбора варианта участник может отозвать согласие и удалить ещё не проголосовавшую сессию с помощью своего токена. Успешная отмена удаляет запись активной SQLite-базы, не записывая голос. После голосования эта операция не удаляет агрегированную статистику; точечное удаление уже записанных анонимных голосов не реализовано. Сетевые журналы и резервные копии могут сохраняться отдельно по правилам хостинга.

Статическая демонстрация не записывает голоса на сервер. При наличии Node-сервера оператор сначала публикует вопрос, а только после отдельного согласия пользователя создаётся анонимная сессия сроком до 7 дней. Сервер сохраняет случайный идентификатор сессии, хеш SHA-256 токена доступа, вопрос, время и не более одного выбора. Исходный токен живёт только в памяти вкладки и удаляется после успешного голосования. Дневные агрегаты A/B хранятся до 90 дней. Один голос сессии не доказывает уникальность реального человека; защита от множественных новых сессий пока ограничена. В текущем прототипе нет возможности удалить конкретный анонимный голос после отправки. Закрытие вопроса не означает стирание уже записанных агрегатов.

Счётчики ограничения запросов временно хранят сетевые IP-адреса в оперативной памяти. Обратный прокси и хостинг могут вести собственные журналы. Управление вопросами защищено общим секретом оператора, а не индивидуальными производственными аккаунтами. Вопросы ограничены 14 днями. Резервные копии могут хранить ранее удалённые данные; процедура их удаления вне сервера не подтверждена.

Pilot Studio и Experiment Lab

Pilot Studio хранит контактные заявки с согласием до 90 дней и выдаёт токен удаления конкретной заявки. Experiment Lab хранит анонимные сессии A/B-исследований до 7 дней и агрегированные счётчики до 90 дней. Эти значения описывают технические события, но не подтверждают реальные показы, уникальных покупателей или продажи. Никакой действующей рекламной сети или платёжной системы здесь нет.

Impossible Ventures 其他实验性产品的数据处理

仅在浏览器中运行的创意工具

Appeal 2049、AntiPersona、Brief Theatre、AdBiome 和 Museum of Attention 在浏览器本地处理创意、报告和访客展品，不将这些内容发送到 Node API。用户选择的 JSON 档案在浏览器中导入；下载仅由用户主动发起。浏览器可能保存语言偏好，但网络托管服务仍可能保留普通访问日志。请勿输入真实客户机密。

Creative Pipeline 与 Economics Studio

Creative Pipeline 仅在浏览器内读取支持的创意 JSON，不会复制任意密钥字段；导出待审核广告草稿需要用户主动操作。Commercial Command 的服务器保存还需独立授权。Economics Studio 根据用户假设计算三种财务情景；结果不代表真实成交、收入、财务报表或投资建议。这些本地工具不会向 API 传输草案或财务参数。

Attention Republic — 明确同意的匿名投票

提交选择之前，参与者可以使用自己的令牌撤回同意并删除尚未投票的会话，成功撤回不产生任何票数。投票完成后无法用此功能删改已汇总的计数，也不支持针对历史匿名选票的精确删除。网络代理日志及备份可能采用单独的保留政策。

静态演示不会向服务器记录选票。运行 Node 服务器时，管理员先发布问题，用户明确同意后才能创建保留最多 7 天的匿名会话。服务器记录随机会话 ID、SHA-256 令牌摘要、问题、时间以及至多一个选择。原始访问令牌仅保留在浏览器内存中，成功提交后即被清除。每日 A/B 计数最多保留 90 天。匿名会话选票不是经验证的独立真人，系统不能防止同一人创建多个新会话。当前版本不支持提交后精确删除某一匿名选票；关闭问题也不会立即清除历史聚合计数。

限速程序可能暂时将请求 IP 保存在进程内存中，代理及托管平台也可能记录日志。管理员使用共享服务器密钥，不是企业级身份验证。问题最多保留 14 天。备份可能仍保存已从在线数据库删除的数据，尚无经过验证的离线删除程序。

Pilot Studio 与 Experiment Lab

Pilot Studio 根据同意保存联系申请最多 90 天，并提供删除特定申请的令牌。Experiment Lab 保存明确同意的 A/B 匿名会话最多 7 天，汇总计数最多 90 天。技术事件计数不能证明真实广告展示、独立访客或实际销售。目前没有生产级广告投放和支付系统。
