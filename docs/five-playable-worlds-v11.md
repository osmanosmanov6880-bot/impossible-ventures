# IMPOSSIBLE VENTURES — five playable worlds v1.1.0 beta

Дата: 22 октября 2026 года.
Статус: пять отдельных браузерных творческих игр с реальной логикой выбора; не пять компаний и не пять рекламных сетей.

## 5 завершённых продуктовых WAVE

| Wave | Браузерный продукт | Полноценный результат |
|---|---|---|
| 6 | /apps/anti-persona/ | 4 раунда: анти-аудитория, барьеры, тезис, проверка; авторский контр-портрет и бриф |
| 7 | /apps/brief-theatre/ | 4 акта и обязательная авторская реплика в каждом; законченный рекламный сценарий |
| 8 | /apps/ad-biome/ | 4 поколения креатива: хук, ценность, доказательство, план A/B; эволюционная карта |
| 9 | /apps/museum-of-attention/ | 4 интерактивных экспоната о внимании, выборе, памяти и честном выходе |
| 10 | /apps/attention-republic/ | 5 заседаний вымышленного совета о доверии, бюджете, спонсорстве, приватности и апелляциях |

Во всех пяти мирах доступны три настоящих ответа на каждом шаге; каждый ответ меняет последствия, игровую метрику и структуру итогового отчёта. Выбор можно отменить, а собственную идею — сохранить в итоговый JSON. Brief Theatre требует реплику не короче 8 символов для каждого акта.

Локализованы все сцены, заголовки, выборы, следствия, предупреждения и элементы интерфейса: русский / English / 中文.

## Что работает, а что нет

- Реальные браузерные состояния: начало сценария, выбор, переход по главам, откат, финал, экспорт.
- Мобильный премиальный интерфейс Obsidian Aurora с отдельной цветовой темой для каждого мира, читаемой типографикой, доступными кнопками, состояниями aria-pressed и поддержкой prefers-reduced-motion.
- Собственные авторские игры в браузере; не требуется регистрация или платёжный аккаунт.
- По умолчанию игровой проект и пользовательские реплики не отправляются API, не сохраняются в localStorage и не передаются сторонним аналитическим SDK. Пользователь явно скачивает JSON локально.
- Для загрузки HTML, CSS и JavaScript браузеру требуется сервер статических файлов, однако для прохождения самой игры backend API не нужен.
- Игровые баллы 0–100 — заранее прописанные проектные эвристики, не CTR, не статистика, не конверсии и не рыночное исследование.
- Полностью отсутствуют живые пользователи игровой «республики», реальные голоса, закупка рекламы, генерация ИИ, платёжные транзакции и подтверждённая выручка.
- Для настоящих рекламных кампаний остаются отдельные Commercial Command, Pilot Studio и Experiment Lab, не затронутые симуляциями.

## Архитектура исходного кода

- apps/creative-worlds/worlds.mjs — уникальные сценарии пяти игр, переводы, три игровых размерности и эффекты.
- apps/creative-worlds/engine.mjs — чистый детерминированный движок; выбор ветки, возвращение назад, эвристики, валидация и отчёты.
- apps/creative-worlds/runner.mjs — доступное управление реальным интерфейсом без внешних CDN и без вставки пользовательского HTML.
- apps/creative-worlds/style.css — одна премиальная адаптивная тема с пятью акцентами.
- apps/<world-id>/index.html — пять самостоятельных точек входа.
- services/dead-drop/server.mjs — whitelist новых статических путей, CSP, правильный MIME для JavaScript ES-модулей.
- scripts/build_static_preview.py — создаёт скачиваемую статическую сборку, включая все пять игр, без операторских ключей.
- services/creative-worlds/worlds.test.mjs — тесты игровых движков, локализаций, логики и серверной выдачи.
- services/dead-drop/browser.test.mjs — Playwright-прохождение каждого мира на мобильном экране 390px, откат, переключение языков и скачивание JSON.

## Переход от игры к настоящей рекламной кампании

Commercial Command теперь принимает локальный JSON-результат от каждого нового мира в качестве входных данных для редактора кампаний. Для оператора это полностью реальный путь:

1. Пройти игру без регистрации и скачать iv-<world>-creative-brief.json.
2. Открыть /commercial/ и нажать «Открыть демо без регистрации» для просмотра либо войти в свою организацию по выданному ключу.
3. В блоке «Импортировать результат игры» выбрать скачанный JSON-файл (до 200 КБ); модуль проверяет схему и реальные ветки сценария.
4. Просмотреть автоматически заполненные название, аудиторию, предложение, гипотезы, текст и CTA. Исправить фактические утверждения.
5. Только затем отдельно нажать «Сохранить черновик» с правами владельца/редактора. Без этих прав содержимое не сохраняется на сервере.

Сам импорт не создаёт запись, не рассылает письма, не запускает рекламное размещение, не подтверждает правдивость тезиса и не переносит игровые баллы в бизнес-аналитику.

Код: apps/creative-worlds/bridge.mjs и apps/commercial/app.js. Проверка: services/creative-worlds/worlds.test.mjs плюс сквозной Playwright-сценарий импорта и сохранения кампании только после явного действия.

## Проверка

Node.js 22 или новее:

    git clone https://github.com/osmanosmanov6880-bot/impossible-ventures.git
    cd impossible-ventures
    npm run check
    npm start

Откройте http://localhost:3000/ и выберите мир. Для теста браузерных сценариев используйте закреплённую версию Playwright из .github/workflows/browser-tests.yml. Сборка статической демоверсии:

    python3 scripts/build_static_preview.py

Содержимое _site следует открыть локальным HTTP-сервером: file:// может блокировать импорт ES-модулей. GitHub Pages требует отдельного включения пользователем репозитория.

## Коммерческие и юридические границы

Результат — законченный творческий браузерный продукт с экспортом, а не доказательство массового спроса. Прежде чем продавать рекламу, понадобятся независимое тестирование на реальных добровольных участниках, подтверждённые клиенты, юридическая проверка утверждений, надёжная идентификация, антифрод, платежи и настоящая аналитика. Ни один игровой индекс нельзя представлять как реальные рекламные показы, стоимость привлечения или прибыль.

Для следующего уровня выбрать одну наиболее востребованную механику, провести 15–25 добровольных пользовательских проверок, измерить понимание и готовность платить, затем проверить платёжеспособный пилот.
