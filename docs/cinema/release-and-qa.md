# THE SIGNAL — Cinematic Interactive Engine 2.0

**Проект:** Impossible Ventures. **Тип:** интерактивное веб-кино и повторно используемый сценарный движок. **Статус:** исходники и CI-релиз-кандидат; публичный домен не подтверждён.

## Реальный результат

- **Постановочная концепция, 15-сценная таблица из 17 полей:** [Storyboard & Style Bible](storyboard-and-style-bible.md).
- **15 отдельных векторных кино-композиций:** \`apps/cinema/assets/scenes/scene_00.svg\` … \`scene_14.svg\`. У каждого SVG viewBox 1600×900. Это иллюстрации, **не фотореалистичные фотографии**, не 8K. Рендерятся браузером согласно экрану.
- **15 конкретных промптов:** [Shot Prompts & Assets](shot-prompts-and-assets.md). Опциональные фотографические кадры пока не поставляются и не загружаются: присутствуют точные имена \`assets/stills/scene_XX.webp\`, которые можно подключить после генерации и проверки размера/лицензии.
- **Полноценная интерактивная история:** \`/cinema/\`; трёхсценный самостоятельно работающий вертикальный срез \`/cinema/prototype/\`.
- **Три сюжетных маршрута:** человек / история / доказательства. **Вторая развилка:** добровольность / давление, с разными сценами и возможностью исправить курс. Скрытый архив открывается только после изучения трёх разных фрагментов.
- **Конечный и проверяемый граф:** все ID, переходы, уникальность выборов, отсутствие недостижимых сцен, 1 итог проверяются кодом \`validateFilm\`.
- **Реальные функции:** интерактивные предметы и записи, журнал посещённых сцен, возврат и смена решения, финальный выбор среди семи существующих проектов, переход к Commercial Command, сброс истории, горячие клавиши.
- **CINEMATIC/BALANCED/LITE:** три режима; AUTO учитывает reduced-motion, viewport, Save-Data и доступную память. Canvas-частицы отключаются для LITE и фоновой вкладки. Камера работает как медленный CSS push/pull/pan без платного видео, масштаб движения 2–5%.
- **Звук:** небольшой авторский синтезатор на WebAudio, без музыки третьих лиц. Инициализация строго после нажатия «Включить звук»; громкость регулируется, выключение закрывает контекст. Текст каждой сцены доступен без звука.
- **Приватность:** игра работает в памяти вкладки без бизнес-API, без телеметрии, без идентификации. Прогресс сохраняется в localStorage **только после отметки отдельного чекбокса**, отключение удаляет его. Обычные запросы за HTML/CSS/JS/SVG обслуживает сервер; провайдер может вести собственные серверные логи.
- **Публикация:** безопасный self-contained статический каталог GitHub Pages, не содержащий секретов оператора, клиентские предложения или базы данных.

### Реальная роль проекта

Это презентационная интерактивная кинематографическая история о продуктовой экосистеме, **не доказательство реальных рекламных показов, массовой аудитории, коммерческой эффективности или миллиардной выручки**. Имеющийся графический материал — самостоятельно написанные SVG-постановки. Для истинной фотографии потребуются отдельные сцены WebP, визуальная проверка и актуальный asset manifest. Нельзя выдавать иллюстрацию или апскейл за «настоящие 8K».

## Как запустить

Нужен Node.js 22+:

\`\`\`bash
git clone https://github.com/osmanosmanov6880-bot/impossible-ventures.git
cd impossible-ventures
npm run check
npm start
\`\`\`

Открыть **http://localhost:3000/cinema/** (полный фильм) или **http://localhost:3000/cinema/prototype/** (прототип на трёх сценах). На главной есть отдельная кнопка **«Смотреть THE SIGNAL»**.

Проверка только кино-движка:

\`\`\`bash
node --test services/cinema/engine.test.mjs
\`\`\`

Для Playwright в CI используется закреплённая версия 1.55.0:

\`\`\`bash
npm install --no-save --package-lock=false playwright@1.55.0
npx playwright install chromium
node --test services/cinema/browser.test.mjs
\`\`\`

Сборка статического каталога:

\`\`\`bash
python3 scripts/build_static_preview.py
python3 -m http.server 8080 -d _site
\`\`\`

После этого **http://localhost:8080/cinema/**, включая прототип, работает без Node API. Нельзя открывать HTML напрямую через \`file://\`: браузер может блокировать ES-модули.

### Звуковое и визуальное качество

| Ресурс | Фактический источник | Факт о разрешении и цене |
|---|---|---|
| 15 фонов | Исходный SVG 1600×900 viewBox | Вектор, браузер выводит под экран; не фотография/не 8K |
| Оптика и камера | CSS transforms и лёгкая pointer-параллакс | 0 дополнительных серверных GPU / видеовызовов |
| Пыль/частицы | Canvas 2D, 17 или 42 частицы | LITE = 0; отрисовка прекращается в фоновой вкладке |
| Аудио | WebAudio OscillatorNode | Нет облачной генерации или чужой музыки |
| Интерактивность | Конфигурация 15 сцен, чистая JS-машина состояний | Работает локально после загрузки статических файлов |
| Дополнительные реалистичные кадры | Подготовленные prompts | Нельзя заявить как готовые до создания и ручной проверки |

**Ограничения:** нет встроенного AI-video, нет реалистичных последовательных актёров, нет видео с захватом движения и нет подтверждённой независимой визуальной экспертизы. Для желаемого впечатления «фотореализм» требуется создание и подключение отдельных постановочных stills.

## Проверка качества перед выпускающим merge

- Структура сюжета валидна, 15 сцен достижимы, единственный финал.
- Трёхсценный прототип завершает все три маршрута, позволяет возврат и перезапуск.
- Полный путь: пролог → маяк → архив → человек / история / доказательства → поворот → музей → совет → последствия → кульминация → финал.
- Секретная сцена заблокирована при 0–2 находках и доступна при трёх разных фрагментах.
- SVG каждого кадра реально отдаётся веб-сервером с MIME image/svg+xml, ES-модули — JavaScript, CSP запрещает внешние скрипты.
- На 390px нет горизонтальной прокрутки или неработающих кнопок, caption виден без звука.
- AUTO и LITE не требуют Canvas/видео; движение отключается для prefers-reduced-motion.
- Нет фоновых сетевых запросов аналитики, платежей или экспериментальных событий.
- Возврат восстанавливает историю, локальный прогресс записывается только после opt-in.
- Существующие Commercial Command, семь продуктовых прототипов, Pilot Studio и резервное копирование SQLite не изменены по своей логике.

**Для публичного деплоя** GitHub Pages нужно отдельно включить в Settings → Pages → Source: GitHub Actions, если эта настройка ещё не сделана. Не следует считать сборку артефакта подтверждённым публичным сайтом.
