# THE SIGNAL · production asset specification / 15 stills

**Rendered assets already in source:** `apps/cinema/assets/scenes/scene_00.svg`–`scene_14.svg`, 1600×900 viewBox vector. These are original atmospheric SVG scene compositions, **not photorealistic renders**. Actual output pixel dimensions depend on the screen and browser rasterization; we do not call them 8K.

**Optional photographic upgrades:** `apps/cinema/assets/stills/scene_00.webp`–`scene_14.webp`. Recommended master **2560×1440, 16:9**; export optional **1280×720** for standard screens and mobile image crops only after checking subject position. Original generated resolution must be logged separately after creation. Do not stretch or falsely label 8K. Keep file size below 450 KB for most 1280px WebP shots, under ~900 KB for selected 2560px masters where quality requires it; this is a target, not a verified measurement.

**Shared continuity:** the same milky-white signal beacon, basalt-and-titanium surfaces, analog-future industrial design, truthful optics and directional lighting; no named film references or copyrighted characters. Foreground, mid-ground and background intentionally distinct. Every frame reserves legible dark negative space on the left for live DOM titles and buttons. No title, labels, icons, graphics, text or logo should be baked into an image. Not all frames should share the same hue. Motion is performed by HTML/CSS/Canvas. If optional WebP are unavailable, scene-specific SVG artworks remain fully functional.

**Common negative prompt:** no embedded text, no lettering, no watermarks, no logos, no screens of fictional metrics, no distorted anatomy, no repeated identical buildings, no overdone lens flares, no excessive depth-of-field blur, no high-contrast content beneath required text, no impossible floating physical elements unless architecturally plausible.
