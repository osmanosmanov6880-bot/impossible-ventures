# Release roadmap

## Next: production readiness
1. Gather 10–20 user interviews per MVP and document success criteria.
2. Move prototypes to typed components, with automated interaction tests.
3. Add server-backed accounts, consent, storage, rate limiting and audit logs.
4. Introduce an LLM only with evaluation sets, safety boundaries and cost limits.
5. Implement accessibility audits, analytics consent and privacy disclosures.
6. Verify legal name/domain availability and regional billing compliance.
7. Deploy preview and production with monitoring and rollback.

Do not describe either prototype as AI-powered yet: both are deterministic. Do not collect sensitive campaign information in the demos.
